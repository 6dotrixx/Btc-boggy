# raw/ — Immutable source documents

Drop source documents here: articles, PDFs, notes, clipped web pages,
transcripts. If you use Obsidian's Web Clipper, set its default folder to this
`raw/` directory.

**Rules:**

- Files here are **immutable ground truth**. Jarvis reads them but never edits
  them.
- One file per source. Markdown preferred; PDFs and text are fine.
- After adding a file, tell Jarvis: **"Ingest the new file in raw/"**.

Everything Jarvis writes lives in `../wiki/`, never here.
